# templates — 模板索引

> **类型**：C 类子目录  ｜  **父目录规则**见仓库根 `CLAUDE.md`
> 本文件本身也是「C 类目录 _INDEX」的范例（极简：规则 → 文件索引 → 变更日志）。

## 规则

- 模板文件命名：`{名称}.md.template`，内容用占位符 + HTML 注释引导，不带具体项目信息
- 使用方式：复制模板到目标目录，替换 `{占位}` 内容；基于毛球 App 的成品示例见 `examples/`
